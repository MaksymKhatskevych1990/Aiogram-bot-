# Инструкции по безопасности

## Конфиденциальные файлы

⚠️ **НИКОГДА не загружайте следующие файлы в публичный репозиторий:**

### Обязательно исключить:
- `.env` и `.env.*` - файлы с переменными окружения
- `service_account.json` - учетные данные Google Service Account
- `*.session` - файлы сессий Telethon
- `celerybeat-schedule*` - файлы планировщика Celery
- QR коды в папке `qr_codes/`

### Настройка проекта

1. **Скопируйте `.env.example` в `.env`:**
   ```bash
   cp .env.example .env
   ```

2. **Заполните `.env` своими реальными данными:**
   - BOT_TOKEN - токен вашего Telegram бота от @BotFather
   - TELEGRAM_API_ID и TELEGRAM_API_HASH - с сайта my.telegram.org
   - ADMIN_CHAT_ID - ID чата администратора
   - Все ключи API для blockchain сервисов
   - Параметры Redis

3. **Настройте Google Service Account:**
   - Создайте Service Account в Google Cloud Console
   - Скачайте JSON файл с ключами
   - Сохраните его как `service_account.json` в корне проекта
   - Либо используйте переменные окружения GOOGLE_* из .env

4. **Проверьте `.gitignore`:**
   ```bash
   git status
   ```
   Убедитесь, что конфиденциальные файлы не отображаются в списке для коммита

## Если случайно закоммитили секреты

Если вы случайно закоммитили конфиденциальные данные:

1. **Немедленно смените все скомпрометированные ключи и токены**
2. Используйте `git-filter-repo` или `BFG Repo-Cleaner` для очистки истории:
   ```bash
   # Установите git-filter-repo
   pip install git-filter-repo
   
   # Удалите файл из истории
   git filter-repo --path service_account.json --invert-paths
   ```

3. **Форсированный пуш** (только если репозиторий приватный и вы единственный разработчик):
   ```bash
   git push --force
   ```

## Лучшие практики

- ✅ Используйте переменные окружения для всех секретов
- ✅ Добавляйте все конфиденциальные файлы в `.gitignore` до первого коммита
- ✅ Регулярно проверяйте `git status` перед коммитом
- ✅ Используйте `.env.example` как шаблон для других разработчиков
- ✅ Никогда не логируйте секреты в консоль или файлы
- ❌ Не храните секреты в коде
- ❌ Не коммитьте файлы с реальными учетными данными
