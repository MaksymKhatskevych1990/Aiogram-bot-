# Менеджер ботов - Инструкция по использованию

## Описание

Менеджер ботов (`bot_manager.py`) автоматически читает токены ботов из базы данных и запускает отдельные процессы для каждого активного бота. Это позволяет использовать **один код** для обслуживания **множества ботов** с разными токенами.

## Как это работает

1. **Пользователь добавляет бота через интерфейс:**
   - Выбирает шаблон бота в магазине
   - Вводит токен бота (полученный от @BotFather)
   - Токен сохраняется в БД через `/bots` endpoint

2. **Менеджер ботов автоматически:**
   - Периодически проверяет БД на наличие активных ботов (каждые 30 секунд)
   - Для каждого активного бота запускает отдельный процесс `main.py` с токеном этого бота
   - Отслеживает состояние процессов и перезапускает упавшие боты
   - Останавливает боты, которые были деактивированы в БД

3. **Каждый процесс бота:**
   - Работает независимо с собственным токеном
   - Использует общий код из одной папки
   - Сохраняет транзакции в БД с привязкой к своему `bot_id`

## Установка и запуск

### 1. Установите зависимости

```bash
cd Aiogram-bot-/Aiogram-bot-/
pip install -r requirements.txt
```

### 2. Настройте переменные окружения

Создайте файл `.env` или установите переменные окружения:

```bash
# URL backend API (где хранятся боты в БД)
BACKEND_API_URL=http://localhost:8000
# или для production:
# BACKEND_API_URL=https://your-backend-domain.com

# Redis для FSM (обязательно)
REDIS_URL=redis://localhost:6379
REDIS_DB_FSM=0

# Опционально: API ключ для аутентификации запросов к backend
BOT_API_KEY=your_api_key_here

# Интервал проверки БД (в секундах, по умолчанию 30)
BOT_MANAGER_CHECK_INTERVAL=30
```

### 3. Запустите менеджер ботов

```bash
python bot_manager.py
```

Менеджер будет:
- Подключаться к backend API
- Читать список активных ботов из БД
- Запускать процессы для каждого бота
- Мониторить состояние процессов

## Структура файлов

- `main.py` - основной скрипт бота (принимает токен через `--token`)
- `bot_manager.py` - менеджер, который запускает несколько экземпляров `main.py`
- `config.py` - конфигурация (теперь токен передается динамически)
- `handlers/` - обработчики команд бота
- `utils/` - утилиты для работы с backend

## Как добавить нового бота

1. **Через веб-интерфейс:**
   - Зайдите в "Магазин Ботов"
   - Выберите шаблон (например, "Бот Обменник")
   - Введите токен бота от @BotFather
   - Нажмите "Создать бота"

2. **Бот автоматически появится в БД** со статусом `active`

3. **Менеджер ботов** (если запущен) автоматически обнаружит нового бота в течение 30 секунд и запустит его

## Мониторинг

Менеджер ботов выводит в консоль:
- `🚀 Запуск бота ID=X` - когда запускает новый бот
- `✅ Бот ID=X запущен (PID: Y)` - успешный запуск
- `⚠️ Процесс бота упал, перезапускаем` - автоматический перезапуск
- `🛑 Остановка бота` - когда останавливает бота

## Остановка

Для корректной остановки всех ботов нажмите `Ctrl+C`. Менеджер остановит все запущенные процессы ботов.

## Важные замечания

1. **Один менеджер на сервер** - не запускайте несколько экземпляров `bot_manager.py` одновременно

2. **Backend должен быть доступен** - менеджер подключается к `/bots/all-active` endpoint

3. **Каждый бот работает в отдельном процессе** - это позволяет изолировать ошибки и перезапускать боты независимо

4. **Токены хранятся в БД** - не нужно создавать отдельные папки или файлы конфигурации для каждого бота

## Решение проблем

### Бот не запускается

1. Проверьте, что токен валидный (через `/bots/validate`)
2. Проверьте, что бот имеет статус `active` в БД
3. Проверьте логи менеджера ботов

### Транзакции не отображаются

1. Убедитесь, что бот запущен (проверьте логи менеджера)
2. Проверьте, что `BACKEND_API_URL` указывает на правильный backend
3. Проверьте, что транзакции создаются с правильным `bot_id`

### Процесс бота постоянно падает

1. Проверьте логи конкретного процесса бота
2. Убедитесь, что Redis доступен
3. Проверьте, что все зависимости установлены
